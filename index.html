Theory

How K-Means works

  1. Choose K, the number of clusters.
  2. Place K starting centroids. k-means++ picks them spread apart, which gives better results than a purely random start.
  3. Assignment step E-step: give every customer to its nearest centroid, using Euclidean distance.
  4. Update step M-step: move each centroid to the mean of the customers assigned to it.
  5. Repeat steps 3 and 4 until no customer changes cluster.
WCSS = Σk Σx ∈ Ck ‖x − μk‖²

K-Means minimises WCSS. Each run can stop at a local minimum, so the model is trained 10 times from different starts and the run with the lowest WCSS is kept.

Link to EM and Gaussian mixtures

K-Means is a "hard" special case of the EM algorithm for a mixture of Gaussians.

K-MeansGaussian mixture (EM)
AssignmentHard: one cluster per pointSoft: a probability for each cluster
E-stepNearest centroidResponsibilities γ(znk)
M-stepCentroid = meanUpdate μ, Σ and mixing weights π
Cluster shapeRound, similar sizeElliptical, any size

Limitations of K-Means: K must be chosen in advance, results depend on the starting centroids, it is sensitive to outliers, and it only works on numeric features.
